# 롤프로 시뮬레이터 웹앱

자기 API 키를 넣어 바로 플레이하는 정적 웹페이지다. 서버가 없고, 키는 플레이어 브라우저(localStorage)에만 저장된다.

## 사용자가 직접 할 일

### 1. 페이지 올리기 (GitHub Pages)
1. 저장소 **Settings → Pages**를 연다.
2. **Source**를 `Deploy from a branch`로, **Branch**를 `main`, 폴더를 `/ (root)`로 정하고 Save를 누른다.
   - 앱이 `rules/` 폴더의 DB를 읽기 때문에 `/docs`가 아니라 **루트**로 정해야 한다.
3. 몇 분 뒤 `https://jyoon00-cloud.github.io/aich/app/`에서 열린다.

비공개 저장소는 GitHub 유료 플랜(Pro 등)이어야 Pages를 쓸 수 있다. 무료 계정이면 다음 둘 중 하나를 고른다.
- 저장소를 공개로 바꾼다. 이 경우 규칙 문서와 DB도 공개된다.
- 아래 '내 PC에서 실행'을 쓴다.

### 2. API 키 만들기
쓰려는 서비스 하나에서 키를 만든다.

| 서비스 | 할 일 |
|---|---|
| OrcaRouter | orcarouter.ai 가입 후 키 발급 (`sk-orca-…`) |
| OpenRouter | openrouter.ai 가입 → 크레딧 충전 → 키 발급 |
| Anthropic | platform.claude.com에서 키 발급 |

키에는 **사용 한도(월 예산)**를 걸어 두는 것을 권한다.

### 3. 앱 설정
1. 페이지에서 **설정**을 누르고 제공자, API 키, **모델 이름**을 넣는다.
   - 모델 이름은 각 서비스의 모델 목록에 적힌 이름을 그대로 복사한다.
   - Anthropic을 고르면 `claude-opus-5-5`가 기본으로 들어간다.
2. **새 게임**을 누르고 시작 연도(2013~2026)를 고르면 캐릭터 생성부터 시작한다.

## 플레이 팁
- **세이브 요청** 버튼을 누르면 AI가 세이브(YAML)를 출력하고, 앱이 그걸 기억한다. 대화가 길어지면 최근 N턴(설정)과 이 세이브만 보낸다. 시즌이 끝날 때마다 한 번씩 눌러 두면 좋다.
- **내보내기**는 대화 전체를 JSON 파일로 저장한다. **불러오기**로 다른 PC나 브라우저에서 이어서 할 수 있다.
- 판정용 주사위는 앱이 매 메시지에 난수를 붙여 보낸다(lolpro.md 0.3).

## 무료 등급에서 '프롬프트가 너무 길다' 오류가 날 때
설정의 **참조 자료 크기**를 '가벼움'(약 3만 자)이나 '최소'(약 1.1만 자)로 바꾸고 새 게임을 시작한다. 연봉·특성·챔피언 상세·포텐셜 파일이 빠지므로, AI가 그 부분을 일반 규칙으로 추정한다. 가장 좋은 건 크레딧을 충전하고 '전체'로 쓰는 것이다.

## 비용 참고
- 매 요청에 규칙과 DB가 약 9만 자(수만 토큰) 들어간다.
- **Anthropic 직접 연결**은 이 부분을 프롬프트 캐싱으로 처리해서 두 번째 턴부터 크게 싸진다. 다른 서비스는 모델에 따라 캐싱 여부가 다르다.
- 응답 최대 토큰과 '기억할 최근 턴 수'를 줄이면 비용이 준다.
- Anthropic 연결에는 서버 측 대체 모델(`fallbacks: "default"`)이 켜져 있다. 안전 분류기가 요청을 거절하면 다른 모델로 자동 재시도하는 기능이다. 끄려면 `app/app.js`에서 `fallbacks`와 `anthropic-beta` 헤더를 지운다.

## 내 PC에서 실행 (Pages 없이)
저장소 루트에서:

```bash
python3 -m http.server 8000
```

그다음 브라우저에서 `http://localhost:8000/app/`을 연다. 파일을 더블클릭해서 열면 DB를 읽지 못하니, 꼭 이 방법으로 연다.
