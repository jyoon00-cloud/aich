# 롤프로 스크립트판 설계서 (Opus 설계)

원칙: **스크립트가 모든 계산과 결과를 정하고, AI는 묘사만 한다.** AI가 없거나 키가 없어도 게임은 끝까지 돌아간다(묘사는 문장 템플릿으로 대신). 규칙 원문은 `rules/lolpro.md`이고, 이 문서는 그것을 코드로 옮기는 범위와 방식을 정한다.

## 0. 파일 구성 (빌드 도구 없음, `<script>` 순서대로 로드)

| 파일 | 내용 |
|---|---|
| `app/index.html` | 화면 틀 |
| `app/style.css` | 모바일 우선, 라이트/다크 |
| `app/js/rng.js` | 시드 난수. 참고 파일의 sfc32 + splitmix32 + hashString을 가져온다(`create(seed|state)`, `int(n)`, `range(a,b)`, `chance(p)`, `pick`, `gauss`, `state()`) |
| `app/js/data.js` | `rules/` 아래 CSV·MD 로드와 파싱(연도별 선수, potential, champions, meta, traits 표) |
| `app/js/rules.js` | lolpro.md 수치표를 상수로: 성장표, 에이징표, 컨디션표, 데뷔 적응표, 히든 스탯 보정, 승격 기준, 연봉 범위 |
| `app/js/state.js` | 상태 객체 생성·저장·불러오기·내보내기(JSON) |
| `app/js/create.js` | 캐릭터 생성(이름, 닉네임, 포지션, 시작 연도, 5개 능력치 자유 입력, 배경 3지선다 생성, 히든 스탯 비공개 굴림) |
| `app/js/week.js` | 주간 진행: 훈련 성장, 솔로랭크, 이벤트, 일정, 에이징(1월 1일) |
| `app/js/mastery.js` | 챔피언 숙련도·시그니처·픽 점수(12.1) |
| `app/js/match.js` | 경기 엔진(5.3), 밴픽 |
| `app/js/league.js` | 리그·팀·일정·순위·플레이오프·국제대회·이적 시장 |
| `app/js/narrate.js` | AI 묘사(선택). 사실 묶음을 받아 짧은 서술을 만든다. 실패하거나 키가 없으면 템플릿 |
| `app/js/ui.js` | 허브, 피드 카드, 선택 모달, 설정 |
| `app/js/main.js` | 턴 루프 |

기존 AI 채팅판은 `app/chat/`으로 옮겨 둔다.

## 1. 상태 (state)
```js
{
  version: 1, seed, rng: [4 uint32],
  date: 'YYYY-MM-DD',
  week: 0,                 // 시작부터 지난 주 수
  startYear,
  p: {
    name, nick, pos,       // pos: TOP/JUNGLE/MID/AD/SUP
    birth: 'YYYY-MM-DD',   // 시작 연도 1월 기준 만 15세
    stats: {lan, phy, skr, tf, vis}, potential: 500,
    hidden: {men, clutch, pro, vol},   // 비공개
    personality: [키워드], speech: 1~5,
    bg: {name, story, merits: [효과], costs: [효과], expires},
    traits: [],            // 일반 특성 id
    pool: [champion id x3~5],
    adapt: {cl: {roll, left}, lck: {roll, left}, intlUsed: false}
  },
  career: {stage: 'amateur'|'academy'|'cl'|'pro', team, league, contract: {start, end, salary, role: 'starter'|'sub'}, money},
  soloq: {tier, lp, mmr, w, l},
  fame: 0~100, community: -100~100,
  record: {official: {w, l}, scrim: {w, l}, kda: {k, d, a}, titles: [], awards: []},
  world: {year, leagues: {LCK: teams..., ...}, schedule, standings, npcs: {id: {team, pos, stats, potential, hidden, traits, age}}},
  feed: [{date, kind, facts, text}],   // 연대기. text는 묘사(AI 또는 템플릿)
  pending: null | {kind, options}       // 선택 대기 (1.2)
}
```
- 매 주 시작 때 `rng` 상태를 저장한다. 같은 상태에서 같은 선택을 하면 같은 결과가 나온다.

## 2. 캐릭터 생성 (lolpro 2장)
- 시작 연도 2013~2026, 만 15세, 무소속 아마추어.
- 5개 능력치는 플레이어가 0~500에서 자유롭게 정한다(합계 제한 없음).
- 히든 스탯은 2.8의 주사위로 비공개 결정한다.
- **배경 3지선다:** 판정형 1, 성장형 1, 예능·이색 1을 뽑아 제시한다.
  - 후보 풀은 `rules.js`에 15개 이상 넣는다(lolpro 2.7 예시를 포함하고 더 만든다).
  - 각 후보는 장점 1~2개와 대가 1개다. 효과 크기는 2.7 표를 따른다.
- 성격 키워드 2~3개는 선택하고, 언변(1~5)은 2d6 표로 굴린다.

## 3. 주간 진행 (턴 = 1주)
허브에서 이번 주 행동 하나를 고른다.

**진행 속도 (사용자 지시, 설정과 허브에서 바꿀 수 있다)**
- **수동:** 한 주씩 행동을 골라 진행한다.
- **자동 진행:**
  - 기간은 1주·4주·12주·다음 경기까지·다음 시즌까지 중에서 고른다.
  - '자동 계획'을 따라 매주 진행한다. 계획은 행동 1개와 집중 능력치 2개다. 예: 훈련(피지컬·교전)
  - 계획에는 '가장 낮은 능력치 자동 집중' 옵션이 있다.
- **멈춤 조건** (체크박스로 켜고 끈다):
  - 선택 대기 이벤트(1.2): 항상 멈춘다.
  - 공식 경기 주
  - 능력치 등급 상승
  - 티어 변화
  - 시즌 종료
  - 매 주 요약 보기
- 자동 진행 중에는 주간 결과를 피드에 한 줄로 모은다. 묘사(AI)는 멈춘 시점의 요약 1회만 요청해 호출 수를 줄인다.
- 경기는 '바로 결과'와 '관전'을 고를 수 있다.

**관전 = 미니맵 SVG + 문자중계 (사용자 지시)**
- 참고 파일의 관전 기능을 가져와 우리 엔진 출력에 맞춘다.
  - `watch()`(6693행~): 미니맵 SVG, 골드 바, 타워·드래곤 표시, 시계, 속도 보통/빠르게, 건너뛰기
  - `cast.js`(9317행~): 세트 결과를 시간순 사건으로 풀기
- `match.js`는 장면 판정 결과로 **타임라인 프레임**을 만든다: `{clock, text, cls, gold, kills, towers, dragons, pos, flash}`
  - 라인전 장면은 0~14분, 교전은 14~25분, 한타는 25분 이후에 배치한다.
  - 장면 사이는 CS·와드·오브젝트 같은 짧은 사건으로 채운다. 결과에 맞춰 스크립트가 템플릿으로 만든다.
- **선수 말 (사용자 지시):** 미니맵 위에 팀당 5개씩, 모두 10개의 말(원 + 포지션 글자 T/J/M/A/S, 플레이어는 강조 테두리)을 둔다. 프레임마다 `pos`로 위치를 옮기고, CSS transition으로 움직인다.
  - 라인전: 각자 라인. 정글은 정글 캠프를 돌다가 갱킹 때 그 라인으로 간다.
  - 교전·오브젝트: 해당 지점으로 모인다.
  - 한타: 한 지점에 모인다.
  - 사망: 말을 흐리게 하고 우물로 보낸다.
  - 귀환: 우물로 간다.
- 문자중계 한 줄은 템플릿으로 만든다. AI 묘사를 켜 두었으면 세트가 끝난 뒤 하이라이트 요약 1회만 붙인다. 중계 줄마다 AI를 부르지 않는다.
- 설정 항목:
  - 관전: 내 경기 전부 / 중요 경기만(플레이오프·국제대회) / 결과만
  - 속도: 보통 / 빠르게

| 행동 | 효과 |
|---|---|
| 훈련 (집중 능력치 2개 선택) | 4.1 성장 판정 |
| 솔로랭크 집중 | 판수 증가, 집중 1개만 성장 |
| 방송 | 인지도 +, 성장 판정 생략 또는 집중 1개 |
| 휴식 | 성장 없음. 슬럼프·부상 회복 |

- **4.1 성장:** 표와 보정(초심자, 소속, 배경, 프로의식, 무소속 300 이상 절반, 비집중 30% +1)을 그대로 쓴다.
- **4.2 에이징:** 1월 1일, 만 25세부터 적용한다.
- **솔로랭크:** 주당 판수는 행동별로 다르다(훈련 15, 솔랭 집중 35, 방송 10).
  - 판마다 승률 = 50% + (OVR − 그 MMR대 평균 OVR) × 0.3%. 5~95%로 자른다.
  - LP는 ±(18~22), MMR이 따라 움직인다.
  - 티어 사다리는 아이언~챌린저. MMR → 대략적인 상대 OVR 표를 `rules.js`에 둔다(예: 챌린저 상위 ≈ OVR 380~420).
- **스카우트 (3장):** 조건이 되면 그 주 이벤트로 제안이 온다(선택 대기).
  - 아카데미: 마스터 이상 + OVR 280 이상, 확률
  - CL: 나이 조건 + OVR 350 이상
  - 1군: 나이 조건 + OVR 400 이상 + 팀 수요. 조건을 넘을수록 확률이 오른다.
  - 리그 출전 연령은 LCK 만 17세(연도별 규정 대신 상수 하나로 둔다)

## 4. 리그와 일정 (league.js)
- 시작 연도 파일(`rules/db/{연도}/{리그}.csv`)로 4대 리그 팀과 선수를 만든다.
  - NPC 능력치는 그 값을 쓰고, potential·히든·특성은 `potential/*.csv`에서 읽는다.
  - 2군(CL) 팀은 1군 팀마다 하나씩 만든다. 선수는 `potential/CL.csv`에서 같은 팀 접두어로 채우고, 모자라면 가상 선수로 채운다.
- **연간 일정은 연도마다 다르다(사용자 지시).** `rules/db/competition.md`의 연도별 절을 구조화한 `app/data/schedule.json`을 만들어 쓴다.
  - 리그마다 그해 대회 목록을 담는다(예: 2025 LCK = LCK컵 → 정규 라운드 → 플레이오프, LPL = 스플릿 1·2·3, LEC = 윈터·스프링·서머).
  - 대회마다 담는 항목: 이름, 시작·종료일, 팀 수, 정규 방식(라운드 수, Bo1/Bo3), 플레이오프(진출 팀 수, Bo5 여부), 승강, 드래프트(일반/피어리스)
  - 국제대회도 연도별로 넣는다: MSI(2020 없음), 월즈, First Stand(2025~), EWC(2024~), Rift Rivals 등 competition.md에 있는 것. 기간, 장소, 리그별 시드, 단계를 담는다.
  - 선발 방식: 리그별 월즈·MSI 진출 팀 결정 규칙
  - `schedule.json`은 competition.md에서만 만들고, 빈 칸은 `null`로 둔다.
- 엔진은 `schedule.json`의 날짜로 주 단위 달력을 만든다.
  - 값이 `null`이면 인접 연도의 같은 리그 규칙을 따른다.
  - 날짜가 없으면 아래 기본 틀로 대신한다: 1~3월 스프링, 4월 PO, 5월 MSI, 6~8월 서머, 8월 말 PO, 10월 월즈, 11~12월 스토브리그.
- 경기 방식(Bo1/Bo3/Bo5, 피어리스)은 대회 데이터를 따른다. 피어리스면 한 시리즈에서 쓴 챔피언을 다시 못 쓴다.
- 2027년 이후는 2026 일정을 연도만 바꿔 반복한다.
- **NPC 경기:** 팀 전력 = 주전 5명 OVR 평균 + 컨디션 난수. 세트 승률 = 50% + 차이 × 0.6%로 빠르게 처리한다.
- **연말 NPC 갱신:** 나이 +1, 에이징 표, 젊은 선수 성장(potential 쪽으로 1d10), 은퇴(만 30세 이상이고 OVR < 420이면 확률).
  - 새 연도 실제 로스터로 맞추지 않는다(db/README 규칙 2).

## 5. 경기 엔진 (match.js, lolpro 5.3)
플레이어가 뛰는 경기만 장면 판정을 한다.
- **컨디션:** 2d6 표에 기복 배율을 곱한다.
- **밴픽:**
  - 플레이어는 풀 안에서 고르거나 '자동'을 쓴다.
  - 챔피언 보정 = (그 장면 값 − 3) × 10이다. 메타 tier S면 +10, A면 +5다. 풀 밖은 −15(난이도 4~5면 −30)이고, 합은 ±30으로 자른다.
  - NPC는 메타 상위에서 고른다.
- **장면:** 라인전 1~2, 소규모 교전 1~2, 한타 1~2. 총 3~6개다.
  - 맞대결: 플레이어 관련 능력치 vs 상대 같은 포지션 선수 능력치(한타는 양 팀 평균)
  - 유효 능력치 = 능력치 + 컨디션 + 데뷔 적응 + 배경 + 히든(승부처 클러치×10, 압박 멘탈) + 특성 + 챔피언
  - 성공률 = 50 + 차이 × 0.3 (5~95)
  - 1d100: 1~5는 대성공, 96~100은 대실패(특성이 범위를 바꿈)
- **승패:** 장면 결과를 골드 우세 점수로 쌓아 정한다(성공 +1, 대성공 +2, 실패 −1, 대실패 −2). 팀 전력 차이도 기본값으로 더한다. 승패를 먼저 정하지 않는다.
- **KDA·POM:** 장면 결과로 만든다.
- **특성 효과:** `traits.md`의 일반·유니크 효과를 코드 표(`rules.js` TRAIT_FX)로 옮긴다. 효과 종류는 장면 보정, 승부처, 열세, 대성공·대실패 범위, 컨디션 처리, 에이징·성장 배율.

## 6. 계약·연봉
- **제안 연봉:** `salary.md`에서 연도·리그·OVR 구간별 범위를 표로 만들어 그 안에서 굴린다.
- **스토브리그 선택지 (선택 대기):** 재계약, 다른 팀 제안 수락, FA 대기
- **역할:** 주전/후보. 후보면 출전 확률이 낮다.

## 7. 이벤트 (1.2 선택 대기)
스카우트, 입단 제안, 이적 제안, 인터뷰·방송 제의, 슬럼프, 부상, 루머, 감독 불화 등.
- 각 이벤트는 조건, 확률, 선택지 2~4개로 정의하고, 선택지마다 결과(능력치·인지도·여론·관계 변화)를 둔다.
- `rules.js`에 15종 이상 넣는다.
- 결과는 스크립트가 정한다.

## 8. 묘사 (narrate.js)
- **입력:** `{kind, date, who, facts: {...}}`. 장면 판정 결과, 이벤트, 경기 결과, 주간 요약 등.
- **AI가 있을 때:**
  - 시스템 프롬프트(짧게): "너는 롤 프로게이머 커리어 게임의 해설·내레이터다. 주어진 사실만 2~5문장 한국어로 묘사한다. 수치·결과를 바꾸거나 새 사실을 만들지 않는다."
  - 입력은 사실 JSON뿐이고 매번 수백 자다. 그래서 무료 등급 길이 제한에 걸리지 않는다.
  - 설정(제공자·키·모델)은 기존 채팅판과 같다(OpenAI 호환 + Anthropic).
- **AI가 없거나 실패할 때:** 종류별 템플릿 문장 여러 개 중 하나를 rng로 고른다.
- 묘사는 피드에 붙이고 저장한다. 다시 불러올 때 재생성하지 않는다.

## 9. 화면 (ui.js)
- **상단 상태 카드:** 날짜(주), 나이, 소속·신분, 솔랭 티어 LP, 5개 능력치와 OVR, 인지도, 계약. 히든 스탯은 숨긴다.
- **허브:**
  - 이번 주 행동 버튼
  - 자동 진행(1·4·12주)
  - 경기 주에는 '경기 진행' 버튼

## 12. v2 수정 (사용자 피드백, Opus 설계)

### 12.1 챔피언 숙련도와 자동 밴픽 (버그 수정 포함)
- **버그:** 피어리스 대회에서 플레이어가 고른 챔피언 하나가 모든 세트에 쓰였다. 세트마다 새로 픽해야 하고, 피어리스면 그 시리즈에서 이미 쓴 챔피언은 다시 쓸 수 없다(양 팀 모두).
- **숙련도:** `p.mastery = {championId: 0~100}`. 플레이어가 입력하지 않고 게임이 정한다(사용자 지시).
  - 플레이어 시작값: 생성 때 포지션 맞는 챔피언 중 그해 메타 상위에서, 능력치 성향(라인전형·교전형 등)과 맞는 챔피언(lan/skr/tf 값) 5개를 골라 40~60을 준다(rng).
  - NPC 시작값: 선수 id 시드로 같은 방식으로 자동 생성한다. 같은 세이브에서는 고정한다. 능력치가 높을수록 숙련도 범위를 올린다(OVR 450↑ 60~85).
  - 성장: 솔랭은 주마다 그 주 주력 3개 챔피언에 +1~3, 공식 경기는 쓴 챔피언에 +3. 상한 100.
  - 감소: 8주 이상 안 쓰면 주당 −1(하한 20).
  - 패치 이벤트(주력 약화)는 meta 점수에만 영향을 준다.
- **자동 픽 (기본):** 세트마다 후보를 고른다.
  - 조건: 내 포지션에 맞음(champions.csv pos), 출시일이 그해 이전, 이번 시리즈에서 사용·밴되지 않음
  - 점수 = 숙련도 + 메타 tier(S +20, A +10, B +5) + 상대 조합 역할 보완(+0~5)
  - 최고점 챔피언을 고른다.
- 숙련도 50 미만 챔피언은 '풀 밖'으로 보고 lolpro 보정(−15, 난이도 4~5면 −30)을 적용한다.
- **밴:** NPC가 양 팀 3밴씩. 상대 핵심 선수의 숙련 상위와 메타 S를 우선한다.
- **수동 옵션:** 설정 '밴픽: 자동 / 중요 경기만 직접 / 항상 직접'. 직접 고를 때는 숙련도 순 목록에서 고르고, 쓸 수 없는 챔피언은 회색으로 표시한다.
- **선수 탭:** 숙련도 상위 15개를 표로 보여 준다(챔피언, 숙련 막대, 이번 시즌 사용 수·승률).

### 12.2 UI 개편 ('AI 게임 냄새' 제거, 일반적인 스포츠 매니저·전적 사이트 디자인 참고)
- **원칙**
  - 문장보다 표와 숫자를 쓴다.
  - 색은 중립 회색에 포인트 색 하나만 쓴다(승리·패배·경고만 의미 색).
  - 그라데이션, 둥근 배지 남발, 이모지를 쓰지 않는다.
  - 숫자는 `font-variant-numeric: tabular-nums`로 오른쪽 정렬한다.
  - 글자 크기는 4단계만 쓴다(12 / 14 / 16 / 20).
  - 카드 그림자는 최소한만, 구분은 1px 선으로 한다.
- **레이아웃**
  - 데스크톱(≥960px): 왼쪽 240px 사이드바(선수 요약: 이름, 팀, OVR, 5개 능력치 미니 막대)와 오른쪽 메인
  - 모바일: 상단 한 줄 헤더(날짜 · 팀 · OVR)와 하단 탭 바
- **탭:** 홈 / 일정 / 순위 / 선수 / 기록 (+ 메뉴)
  - **홈:** 다음 일정 카드, 이번 주 행동(세그먼트 버튼 4개 + 집중 능력치 칩), [진행] 버튼 하나. 자동 진행은 [진행] 옆 드롭다운(1주·4주·다음 경기·시즌 끝)으로 하고, 멈춤 조건은 설정으로 옮긴다. 최근 소식 5줄.
  - **일정:** 그해 달력 목록(날짜, 대회, 상대, 결과). 지난 경기는 결과로, 다음 경기는 강조한다.
  - **순위:** 대회별 순위표(순위, 팀, 승-패, 세트 득실). 내 팀 행을 강조한다.
  - **선수:** 능력치 표(값, 등급, 최근 4주 변화), 숙련도 표, 계약·연봉, 특성(이름만, 수치 비공개), 커리어 기록(시즌별 팀·성적)
  - **기록:** 연대기. 왼쪽에 날짜 열, 오른쪽에 한 줄 요약. 펼치면 묘사가 나온다.
- **경기 결과 화면:** 중계 스코어보드 형식으로 바꾼다.
  - 상단: 팀명·스코어
  - 세트별 한 줄: 승패, 내 챔피언, KDA, 시간, 상대 라이너 챔피언
  - 판정 근거(능력치 비교·성공률·주사위)는 기본으로 숨기고 '판정 상세' 토글에서만 보인다.
  - POM, 시리즈 MVP 표시
- **문구 정리**
  - '주사위', '판정'은 상세 화면에만 쓴다. 본문에서는 결과로 말한다("라인전에서 밀렸다").
  - '지난 0주' 같은 0 표기를 없앤다. 요약은 실제 진행 주 수가 1 이상일 때만 만든다.
- **솔랭 시즌 (사용자 지시):** 주당 판수는 그대로 둔다. 전적·LP·티어를 1월 1일마다 초기화하고, 지난 시즌 최종 티어는 커리어 기록에 남긴다. 새 시즌 MMR은 평균 쪽으로 조금 당긴다(×0.8 + 기본×0.2).
- **관전:** 미니맵·말은 유지한다. 중계 글씨를 14px 단일 열로 하고, 같은 시각 사건은 묶는다.
- **접근성:** 버튼 최소 44px, 포커스 표시, 다크·라이트 모두 대비 4.5:1 이상

### 12.3 시그니처 챔피언 (사용자 지시, 12.1 숙련도 보완)
- **생성 때 선택:** 플레이어가 시그니처 챔피언 3개를 고른다. 내 포지션에 맞고 시작 연도 1월 기준으로 출시된 챔피언에서 검색해 고른다.
  - 시그니처는 숙련 70으로 시작한다. 나머지 숙련은 12.1처럼 자동으로 정한다.
- **이벤트로 추가·교체 (선택 대기, 최대 5개)**
  - 신챔 출시·메타 변화 때 '새 챔피언 연습'
  - 패치로 시그니처가 약화되면 교체·유지 선택
  - 한 챔피언으로 연승하면 시그니처로 올릴지 선택
- **픽:** 기본은 자동(메타 + 숙련). 시그니처에는 보너스를 준다.
  - 픽 점수 +15
  - 경기 유효 능력치 +10
  - 숙련 성장 ×1.5
  - 피어리스에서는 시그니처도 시리즈당 한 번만 쓴다.
- **화면:** 밴픽을 직접 고를 때 시그니처를 맨 위에 둔다. 선수 탭에는 '시그니처' 글자 라벨로 표시한다.
- **NPC와 기존 세이브:** NPC는 숙련 상위 3개를 시그니처로 자동 지정한다. 기존 세이브도 같은 방식으로 옮긴다.

### 12.4 특성 획득은 선택 (사용자 지시)
- 시즌 종료 때 조건을 만족한 일반 특성 후보를 모아 '특성 획득' 모달을 띄운다. 선택 대기 이벤트다.
  - 후보마다 이름, 효과 한 줄, 근거(그 시즌 수치)를 보여 준다.
  - 하나를 고르거나 보류한다. 3개가 꽉 찼으면 교체하거나 보류한다.
- 부정 특성은 고르는 것이 아니라, 근거와 함께 알리는 모달로 붙인다.
- 판정에 쓰는 장면 통계는 시즌마다 새로 센다.
- 부정 특성은 3개 제한 안에서 우선한다. 칸이 차 있으면 가장 늦게 얻은 긍정 특성을 밀어낸다.

### 12.5 시즌 시상 (자율 추가)
- 스토브리그 직전, 로스터가 바뀌기 전에 리그마다 뽑는다.
- 팀 점수: 그해 정규 대회 세트 승률(0~100)에 성적 보너스를 더한다.
  - 리그 플레이오프: 우승 +8, 준우승 +4
  - MSI: 우승 +7, 준우승 +3
  - 월즈: 우승 +14, 준우승 +7
- 선수 점수 = OVR + 팀 점수 × 0.6 + 경기력.
  - NPC 경기력: ±6 무작위
  - 내 선수 경기력: 이번 시즌 KDA와 POM 비율로 계산하고, 10세트 이상 뛰어야 후보가 된다.
- 포지션별 상위 3명이 올-프로 1st·2nd·3rd 팀이 된다. 1st 팀에서 점수가 가장 높은 선수가 MVP다.
  - 인지도: 1st +6, 2nd +3, 3rd +1, MVP +10
- 순위 탭에 표시하고, 수상 내역은 선수 탭 커리어에 남긴다.
