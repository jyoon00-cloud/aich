# AI챗 운영용 개선 제안 (lolpro.md)

우선순위 순. 번호로 골라주시면 반영합니다.

## 🔴 꼭 고칠 것 (AI가 헷갈리거나 지어낼 부분)

1. **존재하지 않는 "기존 규칙" 참조**
   - lolpro §2 "기존 성격 시스템", "기존 언변 수치 시스템", §4.2 "기존에 정의된 나이별 에이징 커브", §2.3 "기존 승격 로드맵"
   - 새 대화의 AI는 이걸 볼 수 없어서 매번 다르게 지어냅니다. → 성격/언변/에이징 커브를 직접 정의하거나, 쓰지 않을 거면 삭제.
   - 예시 에이징 커브: 15~21세 성장 정상, 22~24세 피지컬 성장 -30%, 25세+ 피지컬 연 -5~15, 멘탈·한타·시야는 경험으로 유지/상승.

2. **판정 공식 없음** — 능력치 0~500을 어떻게 성공률로 바꾸는지 없어서 판정이 들쭉날쭉해요. 제안: `성공률 = 50% + (내 능력치 − 상대 능력치) ÷ 5`, 5~95%로 제한. (배경 보정 +30도 이 식에 그대로 들어감)

3. **성장량 수치 없음**
   - "성장 보정 +50%"나 배경 보정 "+20%"의 기준이 되는 기본 성장량이 없음. → 예: 1주 집중 훈련 시 해당 능력치 +3~8, 능력치 300 이상은 팀 소속 없이는 절반 등.

4. **OVR 계산식 모호**
   - "총합 1,500 이하" + "평균 OVR 250"은 사실상 같은 말인데 둘이 따로 있어 혼동 여지. 그런데 승격표는 OVR 200~280부터 시작 → 시작이 평균 250이면 이미 1단계 상한 근처.
   - 제안: `OVR = 6개 능력치 평균(소수점 버림)`을 한 줄로 명시하고, 시작 OVR을 낮출지(예: 총합 1,200, 평균 200) 결정.

## 🟡 있으면 좋은 것

5. **세이브 형식 고정** — §9.1은 항목 나열뿐이라 대화마다 형식이 달라져요. YAML 템플릿 하나를 넣어두면 불러오기가 안정적이에요.
6. **컨디션·평판 수치화** — 상태창 필수 항목인데 척도가 없음. 컨디션 5단계(최상~최악), 평판/인지도 0~100 정도.

## 🟢 토큰 절약
