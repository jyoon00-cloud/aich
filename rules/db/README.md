# 선수 DB 사용 규칙 (AI 디렉터용)

## 파일 구조
- `potential/{LCK|CL|LPL|LEC|LCS}.csv` — 연도와 무관한 글로벌 정보. 포텐셜은 여기서만 읽는다.
- `{연도}/{LCK|LPL|LEC|LCS}.csv` — 그해 **스프링 개막 로스터** 기준 1부 선수의 현재 능력치. (2025 북미는 LTA North를 LCS.csv에 기록)
- `champions/` — 챔피언 정보·연도별 프로 메타. 규칙은 `champions/README.md`.
- `traits.md` — 역대급 NPC의 고유 특성(lolpro §2.9). 해당 선수가 나오는 장면에서만 읽는다.
- 2013~2026 수록. CL·해외 2부는 연도별 파일 없음. `potential/CL.csv`는 LCK CL 2021~2026 스프링(2025~ 킥오프) 로스터 선수 전원이다. 1부에도 뛴 선수는 LCK.csv 등에도 같은 값으로 있다.
- 로스터 출처: Leaguepedia 각 연도 첫 스플릿 Team Rosters(팀당 출전 선수 최대 7명). 2025·2026 LCK는 LCK컵, 2025 LPL·2026 LPL은 스플릿1, 2023~2025 LEC는 윈터, 2026 LEC는 버서스(파트너 10팀만), 2025 북미는 LTA North 스플릿1, 2026 LCS는 락인 기준.
- 능력치·포텐·히든 스탯은 Leaguepedia 성적·국제대회 기록·기사 근거로 정한 산식 값이다(아래 "수치 기준"). 근거가 없는 히든 스탯은 기본값(멘탈 3, 프로의식은 시즌 수 기준)이다.
- 능력치는 **그해 리그 안의 상대적 위치** 기준이다. 연도가 달라도 같은 기준표를 쓴다.

## 읽기 규칙
1. 캐릭터 생성 시 **시작 연도 폴더의 필요한 리그 파일만** 읽는다. 다른 연도 폴더는 읽지 않는다.
2. 이후 NPC 능력치·소속 변화는 시뮬레이션 규칙(성장·에이징·이적 판정)으로만 일어나고 세이브 `npcs`에 기록한다. 시작 연도 이후의 실제 성적·능력치·이적을 근거로 NPC를 바꾸지 않는다.
   - 연도별 파일의 선수단(팀·소속)은 **시작 시점의 구성이자 경향**일 뿐 강제가 아니다. 다음 해 실제 로스터로 맞추지 않는다.
3. 연도별 파일에 없는 선수(CL, 미래 신인)는 `potential` 파일의 포텐셜·출생연도로 현재 능력치를 생성한다. 생성값은 나이에 맞게 포텐셜보다 충분히 낮게 잡고, 생성 즉시 세이브에 고정한다.
4. 미래 신인은 `debut_year` 전후 나이가 되면 아마추어·연습생으로 등장할 수 있다. 소속은 시뮬레이션이 정한다.
5. 한 선수가 여러 리그를 거쳤으면 potential 행은 거친 모든 리그 파일에 같은 값으로 들어 있다.
6. DB에도 세이브에도 없는 선수는 검색하지 않고 같은 기준으로 생성한다.
7. 시작 연도의 리그 구조(형제팀·승강제·2군 리그 유무 등)는 `league_history.md`를 읽고 판단한다.

## 열 정의
potential: `id,name,pos,birth_year,potential,men,clutch,pro,vol,debut_year`
- id: 소문자 닉네임 (중복 시 `_2`). debut_year: 1부 첫 출전 연도, 미데뷔면 비움.
- men(멘탈 1~5), clutch(−2~+3), pro(프로의식 1~5), vol(기복 1~5, 1=안정): 히든 스탯, 고정값 (lolpro §2.8). 커리어 전체 평판 기준. 클러치 +3은 명예의 전당급만. 플레이어에게 수치를 직접 공개하지 않는다.

연도별: `id,team,pos,lan,phy,skr,tf,vis,style`
- lan 라인전·동선 / phy 피지컬 / skr 소규모 교전 / tf 한타 / vis 시야
- style: 한 단어 (캐리형, 운영형, 교전형, 안정형, 이니시형, 로밍형, 성장형, 보호형 등)
- OVR은 저장하지 않는다. 5개 평균으로 계산한다.

## 수치 기준
포텐셜: 일반 상한 490 (제우스·쵸비·케리아급 = 490). 490 초과는 명예의 전당(Faker 500, Uzi·Caps 495)만.
현재 능력치(OVR 기준, 각 능력치는 ±30 내외로 개성 부여, 포텐셜 초과 불가):

| 그해 위치 | OVR |
|---|---:|
| 1부 하위권·신인 주전 | 400~425 |
| 1부 중위권 주전 | 425~445 |
| 1부 상위권 주전 | 445~465 |
| 국제대회 최상위 | 465~485 |
| 역대급 전성기 | 485~495 |

리그 간 차이: 고정값이 아니라 **그해 국제대회 성적으로 매년 정한 리그 보정**이 값에 이미 들어 있다(그해 1위 리그 = 0). 그래서 리그가 달라도 OVR을 그대로 비교한다. 가중치는 월즈 1.0, MSI 0.3, First Stand·EWC 0.1.

### 능력치 산정 방식 (근거 기반, `_work/redo/formula.md`)
- 주전 OVR = 개인 성적(같은 리그·포지션 주전 대비 KDA·KP·DMG/M·CS/M 백분위, 400~470) + 팀 순위 보정(±10) + 직전 해 실적 + 리그 보정.
- 직전 해 실적(합산, 상한 없음): 월즈 우승 +20·준우승 +14·4강 +9·8강 +5, MSI 우승 +6·준우승 +3·4강 +1, First Stand·EWC·지역 리그 우승·리그 MVP·퍼스트 올프로 각 +1.
- 그해 **스프링 개막 시점** 값이다. 그해 국제대회 활약은 다음 해 값에 반영된다.
- 근거: `_work/redo/ev/`(Leaguepedia 성적), 계산 내역: `_work/redo/changes2/`.

### 포텐셜·히든 (`_work/pot2/`)
- potential: 커리어 최고 OVR과 월즈·MSI·리그 우승 기록으로 정했다. 연도별 단일 능력치 이상이며, 명예의 전당(Faker 500, Uzi·Caps 495) 외에는 490이 상한이다(초과하던 연도별 능력치 20칸은 490으로 잘랐다).
- clutch는 결승·국제대회 성적, vol은 연도별 개인 성적 백분위의 변동(성장·에이징 추세 제외), pro는 1부 시즌 수에서 정했다. men·pro는 징계·멘탈 관련 기사를 확인한 선수만 기본값에서 조정했다.
