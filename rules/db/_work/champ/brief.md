# 챔피언 정보 입력 지시 (워커용)

입력: `in/cN.csv` (id,name_en,release,class,attack,resource — 수정 금지). 출력: `out/cN.csv`, 입력의 모든 행을 같은 순서로, 아래 열만 쓴다(헤더 포함):

`id,name_ko,pos,diff,curve,lan,skr,tf,role,rework,note`

- id: 입력 그대로.
- name_ko: 한국 서버 공식 한글 이름 (예: 카이사, 누누와 윌럼프, 르블랑). 확실하지 않으면 음역하고 note 끝에 `(한글명 추정)`.
- pos: 프로 대회에서 쓰인 포지션. TOP/JUNGLE/MID/AD/SUPPORT 중 1~3개를 많이 쓰인 순서로 `/`로 연결 (예: `TOP/MID`). 프로에서 거의 안 쓰였으면 솔로랭크 주 포지션.
- diff: 조작 난이도 1~5 (1 가넷·애니비아급 쉬움 … 5 리븐·아펠리오스·아지르급 어려움).
- curve: 파워가 가장 강한 시기. `초반`/`중반`/`후반` 중 하나.
- lan, skr, tf: 이 챔피언이 라인전 / 소규모 교전(2:2~3:3, 갱킹, 스커미시) / 5:5 한타에서 얼마나 강한지 1~5. 3=평균. 같은 포지션 챔피언끼리 비교한 값이다. 모든 값을 3이나 4로 몰지 말고 개성을 준다.
- role: 조합 내 역할 태그 1~2개, `/`로 연결. 다음 중에서만: 이니시, 돌진, 받아치기, 포크, 스플릿, 보호, 견제, 탱킹, 캐리, 암살, 유틸, 운영
- rework: 프로 활용이 바뀐 대규모 리워크(VGU 등) 연도. 여러 번이면 `2016/2024`. 없으면 비움.
- note: 한국어 한 줄 30자 이내. 프로 경기에서의 핵심 특징 (예: "궁극기 이니시 후 한타 집결형, 블루 진영 선픽 단골").

기준: 챔피언의 현재 버전이 아니라 **프로 대회 역사 전체에서 일반적으로 알려진 모습** 기준. 리워크로 성격이 바뀐 챔피언은 최신 버전 기준으로 쓰고 note에 이전 모습을 짧게 남긴다.
**검증 방식 (v2):** `out/cN.csv`(1차 기억 기반 입력)를 출발점으로, 각 챔피언을 **WebSearch/WebFetch로 확인**해 고친다.
- name_ko: 한국 공식 사이트·인벤·나무위키 등에서 공식 한글명 확인.
- pos: 프로 대회 기록(Leaguepedia, gol.gg, oracle's elixir 등)이나 공략 사이트(op.gg, lolalytics, u.gg)의 포지션 통계로 확인.
- rework: 리그 오브 레전드 위키 등에서 대규모 리워크(VGU) 연도 확인.
- diff/curve/lan/skr/tf/role: 공식 난이도, 공략 사이트·커뮤니티 평가를 근거로 조정.
- `(추정)` 표기는 남기지 않는다. 검색해도 정말 확인이 안 되는 칸만 note 끝에 `(미확인)`.
- 출력: `v2/cN.csv` (같은 열·같은 순서), 그리고 `v2/cN_changes.md`에 바뀐 칸만 `id: 열 이전→이후 (근거 URL)` 형식으로 기록.
CSV 규칙: 쉼표가 들어간 note는 큰따옴표로 감싼다. 행 수는 입력과 같아야 한다.
