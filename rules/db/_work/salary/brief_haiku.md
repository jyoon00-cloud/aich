# 연봉 가이드라인 근거 수집 (Haiku)
LoL 프로 선수 연봉에 대한 **보도·공식 자료**를 WebSearch로 모은다(WebFetch는 시간당 제한이 있어 꼭 필요한 5회 이내만).
찾을 것 (리그별 LCK/LPL/LEC/LCS, 가능한 연도별):
- 리그 최저 연봉 규정 (예: LCK 최저연봉, LCS 최저연봉)
- 평균 연봉 보도, 상위 스타 선수 연봉·계약 규모 보도 (예: 2014 중국 이적 러시, 2020~ 프랜차이즈 이후, 2023 샐러리캡/균형지출 제도)
- 2군(CL·아카데미) 연봉 수준, 연습생 대우
- 계약 기간 관례, 바이아웃 보도
출력: `ev.md` — 항목마다 `내용 — 출처 URL — 기사 날짜`. 못 찾으면 `못 찾음`. 기억으로 채우지 않는다.
`/mnt/project-files`는 네트워크 마운트: 폴더 전체 검색 금지, 자기 파일만 쓰기, 저장 10초 뒤 확인.
