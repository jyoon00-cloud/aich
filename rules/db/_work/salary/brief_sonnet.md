# salary.md 작성 지시 (Sonnet 워커용, Opus 설계)

입력: `_work/salary/ev.md`(하이쿠 근거: 내용 — URL — 날짜), `rules/db/README.md`(OVR 기준표), `rules/lolpro.md`(계약·연봉 관련 규칙이 있으면 맞춘다).
출력: `rules/db/salary.md`. AI 디렉터가 계약·연봉을 정할 때 읽는 가이드라인이다.

## 담을 내용
- 리그별(LCK/LPL/LEC/LCS), 시대별(2013~2014 / 2015~2019 / 2020~2022 프랜차이즈 / 2023~ 균형지출·샐러리캡) 연봉 범위
  - 최저연봉 규정
  - OVR 구간별 1군 주전 범위(하위·중위·상위·최상위 스타)
  - 비주전
  - 2군·아카데미
  - 연습생
- 계약 관례: 기간, 바이아웃, 계약 만료 시기(스토브리그).
- 통화는 원래 단위로 쓰고, 원화 환산은 괄호에 대략으로 쓴다.

## 근거 규칙
- 수치마다 ev.md의 어느 항목에 근거하는지 표시한다(문서 끝 '근거' 절에 번호와 URL 목록, 본문에는 [1] 같은 번호).
- ev.md에 없는 수치
  - 먼저 WebSearch/WebFetch로 확인한다. 기사 본문은 Bash `curl -sSL -A "Mozilla/5.0"`로 연다.
  - 확인하면 ev.md 끝 `## Sonnet 추가` 절에 `내용 — URL — 날짜`로 덧붙이고 쓴다.
- 그래도 없으면 근거 있는 수치(예: 최저연봉, 보도된 스타 연봉)에서 비율로 보간한다. 이때 `(보간: [n] 기준)`이라고 적는다.
- 보간할 근거조차 없으면 `근거 없음 — 시뮬레이터 판단`. **기억으로 수치를 채우지 않는다.**
- 루머·인용 보도는 `(보도)`로 표시한다.
- git 명령은 하지 않는다. 끝나면 짧게 보고: 보간 칸 수, 근거 없음 칸 목록.
