# 2019 근거 (Leaguepedia)

## LCK (LCK 2019 Season, 'LCK/2019 Season')
- 스플릿: 1차 Spring 2019-01-16~2019-03-31 (LCK/2019 Season/Spring Season), 2차 Summer 2019-06-05~2019-08-18 (LCK/2019 Season/Summer Season). 그 외: Spring Playoffs 2019-04-03~2019-04-13 (LCK/2019 Season/Spring Playoffs), Summer Playoffs 2019-08-21~2019-08-31 (LCK/2019 Season/Summer Playoffs), Spring Promotion 2018-09-18~2018-09-22 (LCK/2019 Season/Spring Promotion), Summer Promotion 2019-04-16~2019-04-21 (LCK/2019 Season/Summer Promotion)
- 정규시즌: 10팀 (TeamRoster 기준), 더블 라운드로빈, Bo3 (Spring·Summer 공통). 상위 5팀 플레이오프 진출 [LCK/2019 Season/Spring Season, Summer Season]
- 플레이오프: 상위 5팀, King of the Hill 싱글 엘리미네이션, 1라운드 Bo3, 나머지 Bo5. Spring 우승 → 2019 MSI 진출 (Spring Playoffs 페이지 명시). Summer 우승 → 2019 월즈 본선 (Summer Playoffs 페이지 명시) [LCK/2019 Season/Spring Playoffs, Summer Playoffs]
- 승강제/2군 리그: 있음 — Spring 하위 2팀 Summer Promotion (Spring 9·10위 + CK Spring 1위 + CK Spring Playoffs 승자, 4팀 더블 엘리미네이션, 1라운드 Bo3, 나머지 Bo5, 승자 Summer 진출). Summer 하위 2팀 → LCK Spring Promotion 행 (Summer Season 페이지 명시). Spring Promotion (2018-09, LCK 2018 Summer 9·10위 + CK 2018 Summer 1위 + CK 2018 Summer Playoffs 승자, 4팀 더블 엘리미네이션, 승자 2019 Spring 진출) [LCK/2019 Season/Spring Promotion]
- 드래프트 규칙: 일반 (Peerless 언급 없음 — 2019 캐시 전체 검색). 픽/밴 규칙 명시 페이지 없음: 못 찾음

## LPL (LPL 2019 Season)
- 스플릿: 1차 Spring 2019-01-14~2019-03-31 (LPL/2019 Season/Spring Season), 2차 Summer 2019-06-01~2019-08-18 (LPL/2019 Season/Summer Season). 그 외: Spring Playoffs 2019-04-04~2019-04-21 (LPL/2019 Season/Spring Playoffs), Summer Playoffs 2019-08-22~2019-09-06 (LPL/2019 Season/Summer Playoffs), Regional Finals 2019-09-07~2019-09-08 (LPL/2019 Season/Regional Finals). Spring/Summer Promotion 페이지: NOPAGE (못 찾음)
- 정규시즌: 16팀 (TeamRoster 기준), 싱글 라운드로빈, Bo3 (Spring·Summer 공통) [LPL/2019 Season/Spring Season, Summer Season]
- 플레이오프: 상위 8팀 싱글 엘리미네이션, 전 경기 Bo5. 1·2위 준결승 직행, 3·4위 8강 직행, 5~8위 1라운드 (1·4·5·8 시드 한 브래킷, 나머지 한 브래킷). Spring 우승 → 2019 MSI 진출, 상위 4팀 Rift Rivals 진출 (Spring Playoffs 페이지 명시) [LPL/2019 Season/Spring Playoffs]. Summer 우승 → 2019 월즈 본선 (Summer Playoffs 페이지 명시) [LPL/2019 Season/Summer Playoffs]
- 승강제/2군 리그: 페이지 내 강등·승격 규정 없음 — Spring/Summer Promotion 페이지 NOPAGE → 못 찾음
- 드래프트 규칙: 일반 (Peerless 언급 없음 — 2019 캐시 전체 검색). 픽/밴 규칙 명시 페이지 없음: 못 찾음
- Regional Finals (챔피언십 포인트 상위 3팀, 다만 이미 월즈 진출 팀 제외, KotH 싱글 엘리미네이션 Bo5) 우승 → 2019 월즈 본선 (Regional Finals 페이지 명시) [LPL/2019 Season/Regional Finals]

## LEC (LEC 2019 Season, 리그명 LEC로 변경, 'LEC/2019 Season')
- 스플릿: 1차 Spring 2019-01-18~2019-03-16 (LEC/2019 Season/Spring Season), 2차 Summer 2019-06-07~2019-08-17 (LEC/2019 Season/Summer Season). 그 외: Spring Playoffs 2019-03-29~2019-04-14 (LEC/2019 Season/Spring Playoffs), Summer Playoffs 2019-08-23~2019-09-08 (LEC/2019 Season/Summer Playoffs), Regional Finals 2019-09-13~2019-09-15 (LEC/2019 Season/Regional Finals). Spring/Summer Promotion 페이지 NOPAGE
- 정규시즌: 10팀, 더블 라운드로빈, Bo1 (Spring·Summer 공통) [LEC/2019 Season/Spring Season, Summer Season]
- 플레이오프: 상위 6팀, Bo5. 1·2위 준결승 직행 구조가 아니라 '저거노트(Juggernaut)' 방식: 3위가 5위 또는 6위 선택, 4위는 나머지와 1라운드 → 2라운드 1·2위 저거노트 매치 → 3라운드 → 결승 (페이지 Format 명시). Spring 우승 → 2019 MSI 진출, 상위 3팀 Rift Rivals 2019 진출 (Spring Playoffs 페이지 명시). Summer 우승 → 2019 월즈 본선 (Summer Playoffs 페이지 명시) [LEC/2019 Season/Spring Playoffs, Summer Playoffs]
- 승강제/2군 리그: 페이지상 강등 없음 — Spring·Summer 정규시즌 "All teams receive a Summer Season seed" 문구 (Spring 페이지). Promotion 페이지 NOPAGE → 못 찾음
- 드래프트 규칙: 일반 (Peerless 언급 없음 — 2019 캐시 전체 검색). 픽/밴 규칙 명시 페이지 없음: 못 찾음
- Regional Finals (챔피언십 포인트 상위 4팀, 월즈 진출 팀 제외, KotH 싱글 엘리미네이션 Bo5). 결승 진출 2팀: 승자 월즈 메인 이벤트 2시드, 패자 플레이인 3시드 (페이지 명시) [LEC/2019 Season/Regional Finals]

## LCS (LCS 2019 Season, 'LCS/2019 Season')
- 스플릿: 1차 Spring 2019-01-26~2019-03-24 (LCS/2019 Season/Spring Season), 2차 Summer 2019-06-01~2019-08-04 (LCS/2019 Season/Summer Season). 그 외: Spring Playoffs 2019-03-30~2019-04-13 (LCS/2019 Season/Spring Playoffs), Summer Playoffs 2019-08-10~2019-08-25 (LCS/2019 Season/Summer Playoffs), Regional Finals 2019-09-06~2019-09-08 (LCS/2019 Season/Regional Finals). Spring/Summer Promotion 페이지 NOPAGE
- 정규시즌: 10팀, 더블 라운드로빈, Bo1 (Spring·Summer 공통) [LCS/2019 Season/Spring Season, Summer Season]
- 플레이오프: 상위 6팀, 싱글 엘리미네이션 + Bo5 (1·2위 준결승 직행 구조: 3위 vs 6위, 4위 vs 5위 8강, 준결승 1위가 8강 승자 선택). Spring 우승 → 2019 MSI 진출, 상위 3팀 Rift Rivals 2019 진출 (3위는 준결승 패자 중 정규시즌 순위 높은 팀에 부여, Spring Playoffs 페이지 명시). Summer 우승 → 2019 월즈 본선 [LCS/2019 Season/Spring Playoffs, Summer Playoffs]
- 승강제/2군 리그: 페이지상 강등 없음 — Spring "All teams receive a Summer Season seed". Summer 페이지의 "2020 Spring Season seed" 문구는 주석 처리됨 → 승강 규정 못 찾음
- 드래프트 규칙: 일반 (Peerless 언급 없음 — 2019 캐시 전체 검색). 픽/밴 규칙 명시 페이지 없음: 못 찾음
- Regional Finals (챔피언십 포인트 상위 4팀, 월즈 진출 팀 제외, KotH 싱글 엘리미네이션 Bo5) 우승 → 2019 월즈 본선 [LCS/2019 Season/Regional Finals]

## 국제대회
- MSI: 2019-05-01~2019-05-19. 장소: 플레이인 호찌민 (GG Stadium), 그룹 하노이 (National Convention Center), 녹아웃 타이베이 (Heping Basketball Gymnasium) [2019 Mid-Season Invitational, Venues]. 방식: 초청 13팀 → 플레이인 10팀 중 3팀 진출 → 메인 이벤트 6팀 (페이지 명시 수치) [2019 Mid-Season Invitational, Format]
  - 지역별 초청 (각 지역 스프링 플레이오프 우승 기준): 브라질 (CBLOL Split 1 PO), 중국 (LPL Spring PO), CIS (LCL Spring PO), 유럽 (LEC Spring PO), 일본 (LJL Spring PO), 한국 (LCK Spring PO), 라틴아메리카 (LLA Opening PO), 북미 (LCS Spring PO), 오세아니아 (OPL Split 1 PO), 동남아 (LST Spring 우승), 대만·홍콩·마카오 (LMS Spring PO), 튀르키예 (TCL Winter PO), 베트남 (VCS Spring PO) [2019 Mid-Season Invitational, Format]
- 월즈: 2019-10-02~2019-11-10, 유럽. 장소: 플레이인 베를린 (LEC Studio, Am Studio 20D), 그룹 베를린 (Verti Music Hall), 8강·준결승 마드리드 (Palacio Vistalegre), 결승 파리 (AccorHotels Arena) [2019 Season World Championship, Venues]. 본선 24팀 초청: 중국 3, 한국 3, 유럽 3, 북미 3, 대만·홍콩·마카오 3, 베트남 2, MSI 상위 지역 1팀 (브라질·CIS·일본·라틴아메리카·오세아니아·동남아·튀르키예·베트남 중), 브라질·CIS·일본·라틴아메리카·오세아니아·동남아·튀르키예 각 1 [2019 Season World Championship, Format]
  - 단계: 플레이인 (12팀, 4조 더블 라운드로빈 Bo1, 조 상위 2팀 → 2라운드 8팀 Bo5, 승자 4팀 본선 합류). 본선 그룹 스테이지 (16팀, 4조, 더블 라운드로빈 Bo1, 조 상위 2팀 → 녹아웃, 싱글 엘리미네이션 Bo5) [2019 Season World Championship, Format]
- 선발 방식 (월즈 Qualified 표, 직행 12팀):
  - 중국: LPL Summer 우승 FPX (1시드), Championship Points RNG (2시드), Regional Finals IG (3시드)
  - 한국: LCK Summer 우승 SKT (1시드), Championship Points GRF (2시드). 3시드 DWG는 플레이인 (LCK Regional Finals)
  - 유럽: LEC Summer 우승 G2 (1시드), LEC Regional Finals 우승 FNC (2시드). 3시드 SPY는 플레이인 (LEC Regional Finals 준우승)
  - 북미: LCS Summer 우승 TL (1시드), Championship Points C9 (2시드). 3시드 CG는 플레이인 (LCS Regional Finals)
  - 대만·홍콩·마카오: LMS Summer 우승 JT (1시드), Championship Points ahq (2시드). 3시드 HKA는 플레이인 (LMS Regional Finals)
  - 베트남: VCS Summer 우승 GAM (직행 1팀). VCS Summer 준우승 Lowkey Esports.Vietnam은 플레이인 (2019-09-15)
  - 플레이인 진출 (Qualified for Play-In, 표 상위): DWG, SPY, CG, HKA, Lowkey Esports.Vietnam, UOL.CIS (LCL Summer 우승), ISG (LLA Closing 우승), RY (TCL Summer 우승), FLA (CBLOL Split 2 우승), 일본·오세아니아·동남아 행은 출력 잘림 → 못 찾음
  - 본선 진출 플레이인 승자 4팀: DWG, CG, HKA, SPY (Qualified from Play-In Stage, 2019-10-07·08) [2019 Season World Championship, Participants]
