# 2017 근거 (Leaguepedia)

## LCK (LCK 2017 Season, 'LCK/2017 Season')
- 스플릿: 1차 Spring 2017-01-17~2017-04-02 (LCK/2017 Season/Spring Season), 2차 Summer 2017-05-30~2017-08-06 (LCK/2017 Season/Summer Season). 그 외: Spring Playoffs 2017-04-07~2017-04-22 (LCK/2017 Season/Spring Playoffs), Summer Playoffs 2017-08-12~2017-08-26 (LCK/2017 Season/Summer Playoffs), Spring Promotion 2016-08-22~2016-08-27 (LCK/2017 Season/Spring Promotion), Summer Promotion 2017-04-25~2017-04-29 (LCK/2017 Season/Summer Promotion)
- 정규시즌: 10팀 (TeamRoster 기준), 더블 라운드로빈, Bo3 (Spring·Summer 공통). 상위 5팀 플레이오프 진출 [LCK/2017 Season/Spring Season, Summer Season]
- 플레이오프: 상위 5팀, King of the Hill 싱글 엘리미네이션, 1라운드 Bo3, 나머지 Bo5. Spring 우승 → 2017 MSI 진출 (Spring Playoffs 페이지 명시). Summer 우승 → 2017 월즈 본선 (Summer Playoffs 페이지 명시) [LCK/2017 Season/Spring Playoffs, Summer Playoffs]
- 승강제/2군 리그: 있음 — Spring 하위 2팀 Summer Promotion (Spring 9·10위 + CK Spring Playoffs 1·2위, 더블 엘리미네이션 4팀, 1라운드 Bo3, 나머지 Bo5, 승자 Summer 진출). Summer 하위 2팀은 2018 Spring Promotion 행 (Summer Season 페이지 명시). Spring Promotion (2016-08, CK Summer 2016 PO 1·2위 + LCK Summer 2016 9·10위, 4팀 더블 엘리미네이션, 준결승 Bo3, 결승 Bo5, 승자 2017 Spring 진출) [LCK/2017 Season/Spring Promotion]
- 드래프트 규칙: 일반 (Peerless 언급 없음 — 2017 캐시 전체 검색). 픽/밴 규칙 명시 페이지 없음: 못 찾음

## LPL (LPL 2017 Season)
- 스플릿: 1차 Spring 2017-01-19~2017-04-16 (LPL/2017 Season/Spring Season), 2차 Summer 2017-06-08~2017-08-20 (LPL/2017 Season/Summer Season). 그 외: Spring Playoffs 2017-04-18~2017-04-29 (LPL/2017 Season/Spring Playoffs), Summer Playoffs 2017-08-22~2017-09-01 (LPL/2017 Season/Summer Playoffs), Spring Promotion 2016-08-11~2016-08-13 (LPL/2017 Season/Spring Promotion), Summer Promotion 2017-04-19~2017-04-21 (LPL/2017 Season/Summer Promotion), Regional Finals 2017-09-02~2017-09-03 (LPL/2017 Season/Regional Finals)
- 정규시즌: 12팀 (TeamRoster 기준), 2개 조 (6팀씩). 조 내 더블 라운드로빈 + 상대 조 싱글 라운드로빈 = 팀당 16경기, Bo3. 조별 상위 4팀 플레이오프 진출 (1위 준결승 직행, 2위 8강 직행, 3·4위 가중 Bo5) [LPL/2017 Season/Spring Season, Summer Season]
- 플레이오프: 8팀 싱글 엘리미네이션, 전 경기 Bo5. Spring 우승 → 2017 MSI 진출 [LPL/2017 Season/Spring Playoffs]. Summer 우승 → 2017 월즈 본선 메인 이벤트 [LPL/2017 Season/Summer Playoffs]. Regional Finals (챔피언십 포인트 3~5위, 싱글 엘리미네이션 Bo5) 우승 → 2017 월즈 플레이인 [LPL/2017 Season/Regional Finals]
- 승강제/2군 리그: 있음 — Spring 5·6위 Summer Promotion: 그룹 A·B 6위 간 경기 패자는 LSPL Summer 강등, 승자는 LSPL 2위와 대결 (승자 LPL Summer 진출). 5위 간 경기 승자는 Summer 진출, 패자는 LSPL 3위와 대결 [LPL/2017 Season/Summer Promotion]. Spring Promotion (2016-08, LPL 2016 Summer 5·6위 + LSPL 2016 Summer Playoffs 2·3위, 6팀 2단계 브래킷) [LPL/2017 Season/Spring Promotion]. Summer 2017 페이지: 12팀 전원 다음 시즌 LPL 고정 슬롯 확보 명시 (프랜차이즈 전환)
- 드래프트 규칙: 일반 (Peerless 언급 없음 — 2017 캐시 전체 검색). 픽/밴 규칙 명시 페이지 없음: 못 찾음

## LEC (EU LCS 2017 Season, 'EU LCS/2017 Season')
- 스플릿: 1차 Spring 2017-01-19~2017-04-02 (EU LCS/2017 Season/Spring Season), 2차 Summer 2017-06-01~2017-08-13 (EU LCS/2017 Season/Summer Season). 그 외: Spring Playoffs 2017-04-08~2017-04-23 (EU LCS/2017 Season/Spring Playoffs), Summer Playoffs 2017-08-19~2017-09-03 (EU LCS/2017 Season/Summer Playoffs), Spring Promotion 2016-08-04~2016-08-07 (EU LCS/2017 Season/Spring Promotion), Summer Promotion 2017-04-06~2017-04-14 (EU LCS/2017 Season/Summer Promotion), Regional Finals 2017-09-08~2017-09-10 (EU LCS/2017 Season/Regional Finals)
- 정규시즌: 10팀, 2개 조 (5팀씩). 조 내 더블 라운드로빈 + 상대 조 싱글 라운드로빈 = 13경기, Bo3. 조 상위 3팀 플레이오프 진출 (조 1위 준결승 직행). Spring은 2016 시즌 챔피언십 포인트 상위 2팀을 서로 다른 조에 배치, Summer는 Spring 플레이오프 상위 2팀을 서로 다른 조에 배치, 나머지 8팀 스네이크 드래프트 [EU LCS/2017 Season/Spring Season, Summer Season]
- 플레이오프: 상위 6팀 (조 1위 2팀 준결승 직행, 2·3위 8강), 싱글 엘리미네이션 + 3위전, 전 경기 Bo5. Spring 우승 → 2017 MSI 진출. Summer 우승 → 2017 월즈 본선 메인 이벤트 [EU LCS/2017 Season/Spring Playoffs, Summer Playoffs]
- 승강제/2군 리그: 있음 — Spring 5위 → Summer Promotion (LCS Spring 5위 + EUCS Spring Playoffs 승자, 4팀 더블 엘리미네이션 Bo5). Summer 5위 → 2018 Spring Promotion (Summer Season 페이지). Spring Promotion (2016-08, LCS Summer 하위 3팀 + EUCS Summer Playoffs 상위 2팀, 5팀 2단계, Bo5). Regional Finals (CP 2~5위, 싱글 엘리미네이션 Bo5) 우승 → 2017 월즈 플레이인 [EU LCS/2017 Season/Regional Finals]
- 드래프트 규칙: 일반 (Peerless 언급 없음 — 2017 캐시 전체 검색). 픽/밴 규칙 명시 페이지 없음: 못 찾음

## LCS (NA LCS 2017 Season, 'NA LCS/2017 Season')
- 스플릿: 1차 Spring 2017-01-20~2017-03-26 (NA LCS/2017 Season/Spring Season), 2차 Summer 2017-06-02~2017-08-06 (NA LCS/2017 Season/Summer Season). 그 외: Spring Playoffs 2017-04-08~2017-04-23 (NA LCS/2017 Season/Spring Playoffs), Summer Playoffs 2017-08-19~2017-09-03 (NA LCS/2017 Season/Summer Playoffs), Spring Promotion 2016-08-04~2016-08-07 (NA LCS/2017 Season/Spring Promotion), Summer Promotion 2017-03-31~2017-04-02 (NA LCS/2017 Season/Summer Promotion), Regional Finals 2017-09-08~2017-09-10 (NA LCS/2017 Season/Regional Finals)
- 정규시즌: 10팀, 9주, 더블 라운드로빈, Bo3 (Spring·Summer 공통). 순위: 시리즈 승률 → 게임 승률 [NA LCS/2017 Season/Spring Season, Summer Season]
- 플레이오프: 상위 6팀, 싱글 엘리미네이션 + 3위전, 1·2위 준결승 직행, 3~6위 8강 (8강 후 재시드), 전 경기 Bo5. Spring 우승 → 2017 MSI 진출. Summer 우승 → 2017 월즈 본선 메인 이벤트 [NA LCS/2017 Season/Spring Playoffs, Summer Playoffs]
- 승강제/2군 리그: 있음 — Spring 9·10위 → Summer Promotion (LCS Spring 하위 2팀 + NACS Spring Playoffs 상위 2팀, 4팀 더블 엘리미네이션 Bo5). Summer 9·10위 → 2018 Spring Promotion (Summer Season 페이지). Summer 7·8위 처리는 본문에 명시 없음 (해당 줄 주석 처리) → 못 찾음. Spring Promotion (2016-08, LCS Summer 하위 3팀 + NACS Summer Playoffs 상위 2팀, 5팀 2단계, Bo5). Regional Finals (CP 2~5위, 싱글 엘리미네이션 Bo5) 우승 → 2017 월즈 플레이인 [NA LCS/2017 Season/Regional Finals]
- 드래프트 규칙: 일반 (Peerless 언급 없음 — 2017 캐시 전체 검색). 픽/밴 규칙 명시 페이지 없음: 못 찾음

## 국제대회
- MSI: 2017-04-28~2017-05-21. 장소: 플레이인 브라질 상파울루 (Riot Games Brazil Studio), 그룹·녹아웃 브라질 리우데자네이루 (Jeunesse Arena, 인포박스 address) [2017 Mid-Season Invitational, Format·인포박스]. 방식: 플레이인 → 메인 이벤트 (그룹 4개조 더블 라운드로빈 Bo1, 조 상위 2팀 → 싱글 엘리미네이션 Bo5) [2017 Mid-Season Invitational, Format]
  - 지역별 시드 (초청 13팀, 각 지역 스프링 플레이오프 우승 기준): 브라질 (CBLOL Split 1 PO), 중국 (LPL Spring PO), CIS (LCL Spring PO), 유럽 (EU LCS Spring PO), 일본 (LJL Spring PO), 한국 (LCK Spring PO), 라틴아메리카 북부 (LLN Opening PO), 라틴아메리카 남부 (CLS Opening PO), 북미 (NA LCS Spring PO), 오세아니아 (OPL Split 1 PO), 동남아 (GPL Spring 우승), 대만·홍콩·마카오 (LMS Spring PO), 튀르키예 (TCL Winter PO) [2017 Mid-Season Invitational, Format]
- 월즈: 2017-09-23~2017-11-04, 중국. 장소: 플레이인·그룹 우한 (Wuhan Gymnasium), 8강 광저우 (Guangzhou Gymnasium), 4강 상하이 (Shanghai Oriental Sports Center), 결승 베이징 (Beijing National Stadium) [2017 Season World Championship, Venues]
  - 본선 규모: 24팀 초청 (중국 3, 한국 3, 유럽 3, 북미 3, 대만·홍콩·마카오 3, 동남아 2 (MSI 상위 지역 1팀 포함), 브라질·CIS·일본·LAN·LAS·오세아니아·튀르키예 각 1). 직행 12팀 + 플레이인 승자 4팀 = 본선 16팀 [2017 Season World Championship, Participants 표·Format]
  - 단계: 플레이인 (12팀, 4개조 더블 라운드로빈 Bo1, 조 상위 2팀 → 2라운드 Bo5 8팀, 승자 4팀 본선 합류). 본선 그룹 스테이지 (4조×4팀, 더블 라운드로빈 Bo1, 조 상위 2팀 → 녹아웃) → 녹아웃 (싱글 엘리미네이션 Bo5) [2017 Season World Championship, Format]
