# 2018 근거 (Leaguepedia)

## LCK (LCK 2018 Season, 'LCK/2018 Season')
- 스플릿: 1차 Spring 2018-01-16~2018-03-25 (LCK/2018 Season/Spring Season), 2차 Summer 2018-06-12~2018-08-09 (LCK/2018 Season/Summer Season). 그 외: Spring Playoffs 2018-03-31~2018-04-14 (LCK/2018 Season/Spring Playoffs), Summer Playoffs 2018-08-12~2018-09-08 (LCK/2018 Season/Summer Playoffs), Spring Promotion 2017-09-12~2017-09-16 (LCK/2018 Season/Spring Promotion), Summer Promotion 2018-04-17~2018-04-22 (LCK/2018 Season/Summer Promotion)
- 정규시즌: 10팀 (TeamRoster 기준), 더블 라운드로빈, Bo3 (Spring·Summer 공통). 상위 5팀 플레이오프 진출 [LCK/2018 Season/Spring Season, Summer Season]
- 플레이오프: 상위 5팀, King of the Hill 싱글 엘리미네이션, 1라운드 Bo3, 나머지 Bo5. Spring 우승 → 2018 MSI 진출 (Spring Playoffs 페이지 명시). Summer 우승 → 2018 월즈 본선 메인 이벤트 (Summer Playoffs 페이지 명시) [LCK/2018 Season/Spring Playoffs, Summer Playoffs]
- 승강제/2군 리그: 있음 — Spring 하위 2팀 Summer Promotion (Spring 9·10위 + CK Spring 1위 + CK Spring Playoffs 승자, 4팀 더블 엘리미네이션, 1라운드 Bo3, 나머지 Bo5, 승자 Summer 진출). Summer 하위 2팀 → 2019 Spring Promotion 행 (Summer Season 페이지 명시). Spring Promotion (2017-09, 2017 LCK Summer 9·10위 + CK Summer Playoffs 1·2위, 4팀 더블 엘리미네이션, 승자 2018 Spring 진출) [LCK/2018 Season/Spring Promotion]
- 드래프트 규칙: 일반 (Peerless 언급 없음 — 2018 캐시 전체 검색). 픽/밴 규칙 명시 페이지 없음: 못 찾음

## LPL (LPL 2018 Season)
- 스플릿: 1차 Spring 2018-01-15~2018-04-08 (LPL/2018 Season/Spring Season), 2차 Summer 2018-06-11~2018-09-02 (LPL/2018 Season/Summer Season). 그 외: Spring Playoffs 2018-04-12~2018-04-28 (LPL/2018 Season/Spring Playoffs), Summer Playoffs 2018-09-05~2018-09-14 (LPL/2018 Season/Summer Playoffs), Regional Finals 2018-09-15~2018-09-16 (LPL/2018 Season/Regional Finals). Spring/Summer Promotion 페이지: NOPAGE (못 찾음)
- 정규시즌: 14팀 (Spring 페이지 개요 기준), 2개 조 (East·West 지역 기준 7팀씩, 홈 구장 기준 배정 + 티어 기준 배정). 팀당 19경기 (조 내 더블 라운드로빈 + 상대 조 싱글 라운드로빈), Bo3 (Spring·Summer 공통) [LPL/2018 Season/Spring Season, Summer Season]
- 플레이오프: 조별 상위 4팀 진출, 8팀 싱글 엘리미네이션, 전 경기 Bo5 (1위 준결승 직행, 2위 8강 직행, 3위-4위 가중 Bo5). Spring 우승 → 2018 MSI 진출, Spring PO 상위 4팀 Rift Rivals 진출 (Spring Playoffs 페이지 명시) [LPL/2018 Season/Spring Playoffs]. Summer 우승 → 2018 월즈 메인 이벤트 [LPL/2018 Season/Summer Playoffs]. Regional Finals (챔피언십 포인트 3~5위, 싱글 엘리미네이션 Bo5) 우승 → 2018 월즈 본선 (Regional Finals 페이지 명시)
- 승강제/2군 리그: Spring 페이지: 상위 3팀 지역별 Demacia Cup 2018 Summer 진출 명시. 강등·승격 규정은 조회 페이지에서 확인되지 않음 → 못 찾음
- 드래프트 규칙: 일반 (Peerless 언급 없음 — 2018 캐시 전체 검색). 픽/밴 규칙 명시 페이지 없음: 못 찾음

## LEC (EU LCS 2018 Season, 'EU LCS/2018 Season')
- 스플릿: 1차 Spring 2018-01-19~2018-03-17 (EU LCS/2018 Season/Spring Season), 2차 Summer 2018-06-15~2018-08-19 (EU LCS/2018 Season/Summer Season). 그 외: Spring Playoffs 2018-03-23~2018-04-08 (EU LCS/2018 Season/Spring Playoffs), Summer Playoffs 2018-08-24~2018-09-09 (EU LCS/2018 Season/Summer Playoffs, 결승 주말 마드리드), Spring Promotion 2017-08-17~2017-08-25 (EU LCS/2018 Season/Spring Promotion), Regional Finals 2018-09-14~2018-09-16 (EU LCS/2018 Season/Regional Finals). Summer Promotion 페이지 NOPAGE
- 정규시즌: 10팀, 더블 라운드로빈, Bo1 (Spring·Summer 공통) [EU LCS/2018 Season/Spring Season, Summer Season]
- 플레이오프: 상위 6팀, 싱글 엘리미네이션 + 3위전, 1·2위 준결승 직행, 3~6위 8강 (8강 후 재시드), 전 경기 Bo5. Spring 우승 → 2018 MSI 진출, Spring 상위 3팀 Rift Rivals 2018 진출. Summer 우승 → 2018 월즈 본선 (Summer Playoffs 페이지 명시) [EU LCS/2018 Season/Spring Playoffs, Summer Playoffs]
- 승강제/2군 리그: 페이지상 강등 없음 — Spring·Summer 모두 "All teams receive a Summer / 2019 Spring Season seed" (모든 팀 다음 스플릿 시드). Summer 하위 4팀 2019 Spring 시드 문구는 주석 처리 상태 [EU LCS/2018 Season/Spring Season, Summer Season]. Spring Promotion (2017-08, LCS Summer 5위 + EUCS Summer Playoffs 승자, 4팀 더블 엘리미네이션 Bo5) [EU LCS/2018 Season/Spring Promotion]. Regional Finals (CP 2~5위, KotH 싱글 엘리미네이션 Bo5) 우승 → 2018 월즈 플레이인 [EU LCS/2018 Season/Regional Finals]
- 드래프트 규칙: 일반 (Peerless 언급 없음 — 2018 캐시 전체 검색). 픽/밴 규칙 명시 페이지 없음: 못 찾음

## LCS (NA LCS 2018 Season, 'NA LCS/2018 Season')
- 스플릿: 1차 Spring 2018-01-20~2018-03-18 (NA LCS/2018 Season/Spring Season), 2차 Summer 2018-06-16~2018-08-20 (NA LCS/2018 Season/Summer Season). 그 외: Spring Playoffs 2018-03-24~2018-04-08 (NA LCS/2018 Season/Spring Playoffs, 결승 마이애미 비치), Summer Playoffs 2018-08-25~2018-09-09 (NA LCS/2018 Season/Summer Playoffs, 결승 오클랜드 Oracle Arena), Spring Promotion 2017-08-11~2017-08-13 (NA LCS/2018 Season/Spring Promotion), Regional Finals 2018-09-14~2018-09-16 (NA LCS/2018 Season/Regional Finals). Summer Promotion 페이지 NOPAGE
- 정규시즌: 10팀, 더블 라운드로빈, Bo1 (Spring·Summer 공통) [NA LCS/2018 Season/Spring Season, Summer Season]
- 플레이오프: 상위 6팀, 싱글 엘리미네이션 + 3위전, 1·2위 준결승 직행, 3~6위 8강, 전 경기 Bo5. Spring 우승 → 2018 MSI 진출, 상위 3팀 Rift Rivals 2018 (북미 vs 유럽) 진출. Summer 우승 → 2018 월즈 본선 (Summer Playoffs 페이지 명시). Summer 8강에서 스플릿 우승팀이 준결승 상대 선택 (Summer Playoffs 페이지) [NA LCS/2018 Season/Spring Playoffs, Summer Playoffs]
- 승강제/2군 리그: 페이지상 강등 없음 — Spring·Summer 모두 "All teams receive a Summer / 2019 Spring seed" 문구. Spring Promotion (2017-08, LCS Summer 2017 하위 2팀 + NACS Summer Playoffs 상위 2팀, 4팀 더블 엘리미네이션 Bo5) [NA LCS/2018 Season/Spring Promotion]. Regional Finals (CP 2~5위, KotH Bo5) 우승 → 2018 월즈 플레이인 [NA LCS/2018 Season/Regional Finals]
- 드래프트 규칙: 일반 (Peerless 언급 없음 — 2018 캐시 전체 검색). 픽/밴 규칙 명시 페이지 없음: 못 찾음

## 국제대회
- MSI: 2018-05-03~2018-05-20, 유럽. 장소: 플레이인·그룹 베를린 (Riot European Studios, Berlin-Adlershof), 준결승·결승 파리 (Le Zénith) [2018 Mid-Season Invitational, Venues]. 방식: 초청 14팀 → 플레이인 10팀 중 2팀 진출 → 메인 이벤트 6팀 (페이지 명시 수치) [2018 Mid-Season Invitational, Format]
  - 지역별 초청 (각 지역 스프링 플레이오프 우승 기준): 브라질 (CBLOL Split 1 PO), 중국 (LPL Spring PO), CIS (LCL Spring PO), 유럽 (EU LCS Spring PO), 일본 (LJL Spring PO), 한국 (LCK Spring PO), 라틴아메리카 북부 (LLN Opening PO), 라틴아메리카 남부 (CLS Opening PO), 북미 (NA LCS Spring PO), 오세아니아 (OPL Split 1 PO), 동남아 (GPL Spring 우승), 대만·홍콩·마카오 (LMS Spring PO), 튀르키예 (TCL Winter PO), 베트남 (VCS Spring PO) [2018 Mid-Season Invitational, Format]
- 월즈: 2018-10-01~2018-11-03, 한국. 장소: 플레이인 서울, 그룹 부산, 8강 부산, 준결승 광주, 결승 인천 [2018 Season World Championship, Format·Venues]. 본선 24팀 초청: 중국 3, 한국 3, 유럽 3, 북미 3, 대만·홍콩·마카오 3, 브라질·CIS·일본·LAN·LAS·오세아니아·동남아·튀르키예·베트남 각 1 (MSI 상위 지역 1팀 포함된 구성 명시) [2018 Season World Championship, Format]
  - 단계: 플레이인 (12팀, 4조 더블 라운드로빈 Bo1, 조 상위 2팀 → 2라운드 8팀 Bo5, 승자 4팀 본선 합류). 본선 그룹 스테이지 (4조, 더블 라운드로빈 Bo1, 조 상위 2팀 진출) → 녹아웃 (싱글 엘리미네이션 Bo5) [2018 Season World Championship, Format]
- 선발 방식 (월즈 Qualified 표, 직행 12팀):
  - 한국: LCK Summer 우승 KT (1시드), Championship Points AFs (2시드), Regional Finals Gen.G (3시드) — 3팀 직행 [2018 Season World Championship, Participants]
  - 중국: LPL Summer 우승 RNG (1시드), Championship Points IG (2시드) [2018 Season World Championship]
  - 유럽: EU LCS Summer 우승 FNC (1시드), Championship Points VIT (2시드) [2018 Season World Championship]
  - 북미: NA LCS Summer 우승 TL (1시드), Championship Points 100 Thieves (2시드) [2018 Season World Championship]
  - 대만·홍콩·마카오: LMS Summer 우승 FW (1시드), Championship Points MADT (2시드) [2018 Season World Championship]
  - 베트남: VCS Summer 우승 PVB [2018 Season World Championship]
  - 플레이인 진출 4팀: C9, EDG, G2, G-Rex (Qualified from Play-In Stage, 2018-10-06·07) [2018 Season World Championship]
  - 리그 챔피언십 포인트 구조: Championship Points 상위 팀 2시드, Regional Finals 우승 → 3시드 (지역별)
