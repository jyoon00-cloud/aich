# 2014 근거 (Leaguepedia)

## LCK (2014 명칭 Champions: 'Champions/2014 Season')
- 스플릿: 1차 Spring 2014-03-12~2014-05-24 (Champions/2014 Season/Spring Season), 2차 Summer 2014-06-18~2014-08-16 (Champions/2014 Season/Summer Season). 그 외: Winter 2013-14 2013-11-15~2014-01-25 (Champions/2014 Season/Winter Season, 2014 시즌 이전 스플릿이지만 연도 내 진행). 별도 Spring/Summer Playoffs 페이지 없음 (봄·여름 시즌 페이지 안에 브래킷 단계 포함)
- 정규시즌: 16팀 → 4개 조 (조당 4팀), 조별 리그 단판 더블 라운드로빈 Bo2 (1:1 무승부 승점 1씩, 2:0 승리팀 3점). 조 상위 2팀 브래킷 진출, 하위 2팀은 NLB 리그 (Spring·Summer·Winter 공통) [Champions/2014 Season/Spring Season, Summer Season, Winter Season]. 방식 명칭은 Summer 인포박스 format "Groups + Playoffs"
- 플레이오프: 조 상위 8팀 브래킷 (8강·4강·결승), 모든 브래킷 경기 Bo5 (결승 포함). 8강 탈락팀은 NLB Diamond 연계 (Champions/2014 Season/Spring Season, Summer Season)
- 승강제/2군 리그: 있음 — 조별 하위 2팀은 NLB Platinum League, 8강 패자는 NLB Diamond League로 이동 (Spring·Summer·Winter 페이지 Format). Spring 페이지는 Xenics Storm이 3/5 로스터 미충족으로 예선(Qualifiers)으로 이동한 사례 기록
- 드래프트 규칙: 일반 (피어리스 언급 없음). 결승 최종 게임만 블라인드 픽, 나머지 드래프트 픽 (Spring·Winter 페이지 Format, Summer 페이지도 동일 문구)

## LPL (2014 명칭 Tencent LoL Pro League)
- 스플릿: 1차 Spring 2014-02-22~2014-04-26 (LPL/2014 Season/Spring Season), 2차 Summer 2014-06-14~2014-08-16 (LPL/2014 Season/Summer Season). 그 외: Spring Playoffs 2014-05-24~2014-05-25 (LPL/2014 Season/Spring Playoffs), Summer Playoffs 2014-08-19~2014-08-24 (LPL/2014 Season/Summer Playoffs)
- 정규시즌: 8팀 (Spring 페이지 개요 명시: 8팀; Summer 페이지 개요 명시 없음), 싱글 라운드 로빈 (각 팀이 나머지 팀과 2번씩 = 더블 라운드로빈), Bo2 (1:1 무승부 1점씩, 2:0 3점). 상위 4팀 플레이오프 진출 [LPL/2014 Season/Spring Season, Summer Season]
- 플레이오프: Spring 상위 4팀, 준결승 Bo3, 3·4위전 Bo3, 결승 Bo5 (최종 게임 블라인드 픽). Spring 상위 2팀 Season 4 China Regional Finals 진출 [LPL/2014 Season/Spring Playoffs]. Summer 상위 4팀 더블 엘리미네이션, Bo5 전 경기 드래프트, 결승 승자 브래킷 1-0 선점. 우승 Champion vs Champion 단계, 2·3위 Spring vs Summer 단계 (Regional Finals 진출) [LPL/2014 Season/Summer Playoffs]
- 승강제/2군 리그: 있음(Summer만 명시) — Summer 하위 2팀은 2015 LPL Spring Promotion 으로 강등 [LPL/2014 Season/Summer Season]. Spring 하위 2팀 처리 명시 없음: 못 찾음 (Spring 페이지는 상위 6팀 Summer 시드만 명시)
- 드래프트 규칙: 일반 (Peerless 언급 없음). Spring 플레이오프 결승 최종 게임 블라인드 픽, Summer 플레이오프는 모든 경기 드래프트 [LPL/2014 Season/Spring Playoffs, Summer Playoffs]

## LEC (2014 명칭 EU LCS, 'EU LCS/2014 Season')
- 스플릿: 1차 Spring 2014-01-14~2014-04-03 (EU LCS/2014 Season/Spring Season), 2차 Summer 2014-05-20~2014-07-31 (EU LCS/2014 Season/Summer Season). 그 외: Spring Playoffs 2014-04-15~2014-04-17 (EU LCS/2014 Season/Spring Playoffs), Summer Playoffs 2014-08-07~2014-08-17 (EU LCS/2014 Season/Summer Playoffs, Gamescom 개최). Spring 이전 Winter Promotion 2013-12-05~2014-01-11 (EU LCS/2014 Season/Spring Promotion)
- 정규시즌: 8팀 (Summer 페이지 개요 명시), 11주 리그, 각 팀이 나머지 팀과 4번씩 (4회 라운드 로빈), Bo1. 순위 기준: 승률 → 총승수 → 알파벳 순 (동률 시 상대 전적·타이브레이커) [EU LCS/2014 Season/Spring Season, Summer Season]
- 플레이오프: 상위 6팀 (Spring·Summer 공통). 싱글 엘리미네이션 + 5·3위전. 1·2위 준결승 직행, 3~6위 8강. Spring은 Bo3 (결승 Bo5), Summer는 전 경기 Bo5. Summer 상위 3팀 2014 월드 챔피언십 본선 진출 [EU LCS/2014 Season/Spring Playoffs, Summer Playoffs].
- 승강제/2군 리그: 있음 — Spring 하위 3팀(6~8위)이 Challenger 상위 3팀과 Summer Promotion (Bo5 6팀 시리즈, 각 LCS 팀이 상대 선택 순서 있음). 패자는 Summer Challenger Series #1 강등 [EU LCS/2014 Season/Summer Promotion]. Winter 2013 Spring Promotion 존재 (EU LCS/2014 Season/Spring Promotion, 2013-12-05~2014-01-11)
- 드래프트 규칙: 일반 (Peerless 언급 없음). 픽/밴 규칙 명시 페이지 없음 — 못 찾음 (기본 규칙 외 특이 조항 없음이라고 쓰지 않음)

## LCS (2014 명칭 NA LCS, 'NA LCS/2014 Season')
- 스플릿: 1차 Spring 2014-01-16~2014-04-06 (NA LCS/2014 Season/Spring Season), 2차 Summer 2014-05-23~2014-08-03 (NA LCS/2014 Season/Summer Season). 그 외: Spring Playoffs 2014-04-18~2014-04-20 (NA LCS/2014 Season/Spring Playoffs), Summer Playoffs 2014-08-23~2014-09-01 (NA LCS/2014 Season/Summer Playoffs). Winter Promotion 2013-12-06~2013-12-22 (NA LCS/2014 Season/Spring Promotion)
- 정규시즌: 8팀 (Summer 페이지 개요 명시; Spring 페이지 개요 공란), 11주 리그, 각 팀이 나머지와 4번씩 (4회 라운드 로빈), Bo1. 순위 기준은 EU LCS와 동일 (승률 → 총승수 → 알파벳 순) [NA LCS/2014 Season/Spring Season, Summer Season]
- 플레이오프: 상위 6팀, 싱글 엘리미네이션 + 5·3위전, 1·2위 준결승 직행, 3~6위 8강. Spring은 Bo3 (결승 Bo5), Summer는 전 경기 Bo5. Summer 상위 3팀 2014 월드 챔피언십 본선 진출 [NA LCS/2014 Season/Spring Playoffs, Summer Playoffs]
- 승강제/2군 리그: 있음 — Spring 하위 3팀이 Challenger 상위 3팀과 Summer Promotion (Bo5, 6팀). 패자는 Summer Challenger Series #1 강등 [NA LCS/2014 Season/Summer Promotion]
- 드래프트 규칙: 일반 (Peerless 언급 없음). 픽/밴 규칙 명시 페이지 없음 — 못 찾음
