# competition.md 틀 (Opus 설계)

연도마다 같은 형식. 값은 근거 파일(ev/)에서만 채운다.

## {연도}
### LCK (그해 명칭)
- 스플릿: 1차 {이름} {시작일}~{종료일}, 2차 {이름} {시작일}~{종료일} (그 외 대회 있으면 추가: LCK컵 등)
- 정규시즌: 팀 수, 방식(더블 라운드로빈 등), 경기 방식(Bo1/Bo2/Bo3)
- 플레이오프: 진출 팀 수, 방식, 결승 Bo5 여부
- 승강제/2군 리그: 있음·없음
- 드래프트 규칙: 일반 / 피어리스(하드·소프트)
### LPL / LEC(EU LCS) / LCS(NA LCS·LTA North) — 같은 항목
### 국제대회
- MSI: 기간, 장소, 지역별 시드 수, 방식 (없던 해는 "없음")
- 월즈: 기간, 장소, 지역별 시드 수, 단계(플레이인·스위스·그룹·녹아웃)
- 선발 방식: 각 리그에서 월즈·MSI 진출 팀을 정하는 방식(서킷 포인트, 지역 선발전 등)
